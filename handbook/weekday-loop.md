# Weekday loop

The shape of a normal work session, adapted from the workflow-loop pattern in [dswh/company-os](https://github.com/dswh/company-os) `departments/_canvas-template.md` (sensor → policy → tools → gate → learning). The steps below are the shape; the real instructions live in the Notion SOPs linked in each row — this repo does not restate them.

| Step | What triggers it | Where the actual instructions live |
|---|---|---|
| A client writes | Inbound message from a client (past, alumni, or otherwise) | [If a client writes](https://app.notion.com/p/3c025e30d68b81ada7b7cbf1d50b0d9f) (Notion) |
| Daily/standing work | Start of a work session | [Do this](https://app.notion.com/p/3c025e30d68b8142a971ccdb0d657b22) (Notion) |
| A campaign is running | Promote a Book engagement in flight | [Campaign SOP](https://app.notion.com/p/3c025e30d68b81ea99c0dcf96db7cd2e) (Notion) |
| A retreat is running | Book Retreat engagement in flight | [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5) (Notion) |
| An Uncovery is running | Book Writing or Book Marketing Uncovery in flight | [Uncovery SOP](https://app.notion.com/p/3c125e30d68b815d9dbbd7e59102af3e) (Notion) |
| A PIAB engagement is running | Platform in a Box in flight | [PIAB SOP](https://app.notion.com/p/3c125e30d68b81d5beecda81a111e6b3) (Notion) |
| Money moves | Any invoice, payment, or payout | [How money moves](https://app.notion.com/p/3c125e30d68b81b49524fe7bc9f65c81) (Notion) |
| Handing off to the next PA | End of a PA's tenure, or a shift change | [PA handoff](https://app.notion.com/p/3c125e30d68b8138a686fd8a52313333) (Notion) |
| Before anything external ships | End of any of the above | [reviews/last-gate-checklist.md](../reviews/last-gate-checklist.md) |

## Every step, before you start
Check [locks.md](locks.md). It doesn't change by department or by day of the week.
