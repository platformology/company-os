## How one pass runs

1. **Locks first.** Open [locks.md](../locks.md) and read the ask against it. If a lock stops the ask, say which one in one plain sentence and stop.
2. Open [run-pa](../../skills/run-pa/SKILL.md), then [run-do-this](../../skills/run-do-this/SKILL.md) for today's work. If it isn't on the Do this page, it isn't today's job.
3. **Work that belongs to another seat gets pointed, not done.** Find its row in [seat-job-map.md](../seat-job-map.md) and hand the seat its router.
4. Take one named leftover on this seat's own job. One unit, then the gate — not two.
5. Facts come from `handbook/` or Michael's own word. Anything else is **"not recorded"** — say so out loud rather than filling it in.
6. Run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md), every line, honestly. Then stop and hand it to Michael.
7. **One thing the gate unlocks:** a `company-os` docs pull request may be merged once the gate passed *and* Anthony C. Garcia has done first QC. Nothing else is unlocked, and program repos are never merged at all.
