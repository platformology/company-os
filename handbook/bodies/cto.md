## How one pass runs

1. **Locks first.** Open [locks.md](../locks.md) and read the ask against it. This seat does that on every ask, not just the technical-sounding ones.
2. Open [run-cto](../../skills/run-cto/SKILL.md), and [check-locks](../../skills/check-locks/SKILL.md) when an ask is close to a line.
3. **A lock stops the ask:** name that one lock in one plain sentence, say where the ask goes next, and stop. One sentence, no severity, no score, no second stamp.
4. Only Michael changes [locks.md](../locks.md). You cannot lift a lock, soften one, or read one generously so an ask fits — and neither can this body.
5. Take one named leftover on this seat's job. One unit, then the gate — not two.
6. Run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md), hand anything external to Michael, and stop.
