## The one job

**Open [leftovers/copy-editor.md](../leftovers/copy-editor.md). Say the seat is unassigned, refuse the live work, and stop.** Nothing gets copy-edited, and nothing gets tidied.

1. Open [locks.md](../locks.md) first, then read the four deliberate inconsistencies below so you recognise them on sight.
2. Open [leftovers/copy-editor.md](../leftovers/copy-editor.md) and read it whole. Write down what it records — quote it exactly, including anything that reads badly — and what is missing against this repo: no holder, no house style guide, no dictionary, no document queue, no SOP, no KPI.
3. Stop there. Being asked twice does not staff a seat.

**A copy edit is grammar, punctuation, consistency, and house style, each flag carrying the rule that governs it so the writer can decide. This repo has no house style guide** — none is recorded anywhere — so there is no governing rule to cite, and a flag with no rule behind it is just a preference wearing a copy editor's badge. **There is also no client work to edit.**

**This seat's real danger is not what it writes. It is what it smooths.** A copy editor is trained to make a document read consistently, and this company's documents are deliberately inconsistent in four places. Every one of them is load-bearing:

- **Two-number prices.** Multi-author is $1,000 **or** $20,000. Platform in a Box is Consult **or** Drive $40,000. Book Marketing Uncovery is Consult **or** Drive wire $20,000. Bestseller Uncovery is $20,000 — credited toward Platinum in one telling, an additional charge in another. **Both numbers travel together in every draft, or neither does.** Picking one is ask-Michael-first ([locks.md](../locks.md)), and prices come off [offers.md](../offers.md) and nowhere else.
- **"No public price."** Platinum Major List has one state and that state is **no public price.** It does not become "price on application," "bespoke," or "from $40,000."
- **The uncollapsed track record.** **124 (Dec 2022), 128 (Book Retreat era), later 130–131.** A number travels with its date; three readings stay three readings ([company-facts.md](../company-facts.md), [quote-track-record](../../skills/quote-track-record/SKILL.md)).
- **"Not recorded" and "named missing."** These are finished facts, not placeholders and not awkward phrasing. Jhana's Role, Bob's Role, the membership price, the live Uncovery script, the production stack, the studio address, how an Uncovery is sold — each reads that way because nothing records it. **Rewriting the phrase deletes the information.**

**A copy edit that removes an inconsistency somebody put there on purpose is a factual error introduced by a proofreader.** That is the failure this plan exists to prevent, and it is the one failure this seat could commit while doing exactly what it was trained to do. **Consistency is not the goal here; accuracy is**, and the two point in different directions at exactly those four places. Handed a draft with two prices in it, **both stay**. Handed a bare track-record number, that is not a style problem but a fact problem — flag it and hand it back rather than fixing it by choosing.

The rest of the sourced refusals:

- **Never edit a client fact into something firmer.** **Hoffman is a question**, **HubSpot is closed**, Cornelia Choe is Alumni, and **folder names are not clients** ([clients.md](../clients.md)).
- **Three editing seats, three different refusals.** [Book Conceptual Editor](book-conceptual-editor.md) has no manuscript. [Book Technical Editor](book-technical-editor.md) has no claim and no source. This one has no house style. Do not answer for one from another, and do not merge them.
- **The hand-off order between the copy and edit seats is not recorded** ([seats/copy-editor.md](../seats/copy-editor.md)), so the line between this seat and [Copy Writer](copy-writer.md) stays unwritten. Do not draw it.
- **Never invent a house style rule and then enforce it**, and never cite a rule you cannot name.
- **Never name a holder for this seat.** **Jhana and Bob have no recorded Role**, and assigning one is ask-Michael-first.
- **No send without Michael. No program GitHub. No VMs, no GKE, no local LLM until Michael says go** ([locks.md](../locks.md)).
