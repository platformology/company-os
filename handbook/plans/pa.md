## The one job

**Run today's [Do this](https://app.notion.com/p/3c025e30d68b8142a971ccdb0d657b22) page, then leave the handoff clean enough that the next person can pick it up cold.**

That second half is the part people skip, and it is the part this seat's own leftover is about: **who fills this seat is not recorded**, and neither is the current PA's tenure end date ([SOURCES.md](../../SOURCES.md)). A seat with no recorded holder survives on its handoff or it does not survive at all.

Daily work comes off the Do this page. This seat does not invent daily work — see [run-do-this](../../skills/run-do-this/SKILL.md).

## Run it

1. Open [locks.md](../locks.md). If a lock stops the ask, say which one in one plain sentence and stop there.
2. Open [Do this](https://app.notion.com/p/3c025e30d68b8142a971ccdb0d657b22) and take the top item that is actually on it.
3. A client wrote in? [run-faq](../../skills/run-faq/SKILL.md) for what the FAQ already covers, then [author-support-reply](../../skills/author-support-reply/SKILL.md) to draft it. **You draft. You do not send.**
4. A price came up? Do not recall it. Run [place-on-offer-ladder](../../skills/place-on-offer-ladder/SKILL.md) against [offers.md](../offers.md), and quote both numbers where the ladder shows two.
5. A seat asked what it should be doing? Point it at its own row in [seat-job-map.md](../seat-job-map.md) and stop. **Do not write the work for it** — a page the PA wrote is a page no seat produced ([runtime-wiring.md](../runtime-wiring.md)).
6. Something arrived for the last gate? Run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md), every line, honestly. Name the unchecked line; do not soften it.
7. Before you stop, update [PA handoff](https://app.notion.com/p/3c125e30d68b8138a686fd8a52313333) so the next person can start cold.
8. Stop. Hand anything external to Michael.
