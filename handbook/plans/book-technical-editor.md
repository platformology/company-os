## The one job

**Open the leftover, name what it records, name what it is missing against this repo, and stop.**

**This seat is UNASSIGNED and it checks nothing.** A technical edit is checking claims against sources: a figure against the thing it came from, a citation against the work cited, a statement of fact against a record. It needs two things — a claim, and a source to hold it against. **This repo has neither for any book**, so there is no check to run.

**The specific danger of this seat is the opposite of the other empty seats.** The writing seats are dangerous because they might produce something. This one is dangerous because it might *tidy* something true into something false.
