## The one job

**Open the leftover, name what it records, name what it is missing against this repo, and stop.**

**Start with the name, because the name does not say what the seat is.** "Book copy writer" reads two ways, and they are different jobs:

- **the copy that sells a book** — jacket, back cover, flap, blurb, description, author bio; or
- **copy written inside a book** — the prose, which would put this seat next to [Book Writer](book-writer.md).

**Nothing in this repo says which.** The leftover file on the M1 may say; this plan does not, and **it does not pick.** Guessing which of two jobs a seat is would invent the seat, which is a bigger invention than any single sentence of copy. Name the ambiguity in the write-up and leave it named. Note the neighbours it has to be told apart from either way: [Book Writer](book-writer.md), [Copy Writer](copy-writer.md), and [Sales Writer](sales-writer.md) are all separate leftovers, and the leftover names all four.

**This seat is UNASSIGNED and it writes nothing under either reading.** There is no book — [clients.md](../clients.md) counts **0 Current and 0 Prospect** on the 18 Aug 2026 extract — so there is no jacket to write and no manuscript to write into. No blurb, no back cover, no description, no author bio, no endorsement, no strapline.

**Two traps live specifically in jacket copy, and both are locked shut here:**

- **The bestseller implication.** No page in this repo records a promised list placement. The [offers.md](../offers.md) rungs named Bestseller Uncovery, NYT, SUCCESS, and Platinum Major List are **prices, not promises about an outcome.** Copy that implies a list, a rank, or a number sold is inventing a guarantee the company has not made.
- **The single confident number.** Jacket copy wants "author of 130 books." The track record is **124 (Dec 2022), 128 (Book Retreat era), later 130–131** and it stays uncollapsed — quote a number with its date, never one alone ([company-facts.md](../company-facts.md), [quote-track-record](../../skills/quote-track-record/SKILL.md)).
