# handbook/leftovers/ — the leftover a new hire picks up today

A leftover is a unit of work that is already named in writing, somewhere sourced, and not finished. That definition is [runtime-guts.md](../runtime-guts.md)'s, unchanged. This folder is where that leftover lives as a page a person can open.

**Packs without this page are not enough.** A seat, a body, a desk, a skill, and a leftover file on the M1 still leave a new hire asking "so what do I actually do today." Opening the leftover for a seat answers that. If you finish a leftover below and still have to invent a first sentence, the leftover failed.

## What a leftover is on this page

| | |
|---|---|
| **A leftover is** | The one named hole this seat owns right now, sourced from the seat page, the plan, or [SOURCES.md](../../SOURCES.md), written so a new hire can pick it up cold |
| **A leftover is not** | A start sentence. "I will not send email" and "I'll start by checking" are not leftovers. They are refusals wearing a first line. |
| **A leftover is not** | A second tracker, a queue file, or a place to invent work. See [runtime-guts.md](../runtime-guts.md). |
| **A leftover is not** | Evidence that a seat is staffed. A leftover existing for a seat does not fill it, unpark it, or assign it. |

When a leftover and the seat page disagree, **the seat page wins**, and this page is the thing that gets fixed.

## How to run one

1. Read [locks.md](../locks.md).
2. Open your seat's leftover above.
3. Do exactly the leftover it names. If it says the leftover is the vacancy, say the vacancy and stop.
4. Run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md). Hand anything external to Michael. **Nothing sends.**

One leftover, one gate, one stop. [cheap-loop.md](../cheap-loop.md) already says why.

Named gaps stay named. Full list: [SOURCES.md](../../SOURCES.md).
