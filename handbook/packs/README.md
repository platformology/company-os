# handbook/packs/ — the expert pack, one page per employee

**Written: 21 Aug 2026.**

Every employee already had a **sit-down pack**: a seat page, a body, a desk, a leftover, a plan, and a `run-*` router. That pack answers *sit down and run one pass today*. It does not answer *what does this seat know, which skill runs it, and what is behind it*. This folder is that second pack — the **expert knowledge / skill / support pack** — and it is the one that was missing.

A pack here adds no seat, no holder, no client, no price, and no figure. Every line on every page below is already written somewhere else in this handbook, and each page says where.

## Expert pack vs sit-down pack

| | |
|---|---|
| **The sit-down pack** | [seats/](../seats/README.md), [bodies/](../bodies/README.md), [desks/](../desks/README.md), [leftovers/](../leftovers/README.md), [plans/](../plans/README.md), and that seat's `run-*` router. All of it already exists. This folder does not edit a line of it. |
| **The expert pack** | One page per employee, in this folder: the seat's already-recorded **purpose**; the handbook pages it opens (**knowledge**); the router that runs it (**skill**); and reports-to, leftover today, and the KPI name with Current empty (**support**). |
| **An expert pack is not** | A curriculum, a reading list, a certification, a training plan, or general theory about what a CMO or a COO does at some other company. None of that is recorded in this repo, so none of it is written here. |
| **An expert pack is not** | Evidence that a seat is staffed. A pack existing does not staff a seat, unpark one, or lift a lock. |

Where a pack and a seat page disagree, **the seat page wins**, and the pack is the thing that gets fixed.

## What every page below holds to

- **Sourced only.** Purpose comes from the seat page, leftover today from that seat's leftover, the KPI name from [plans/README.md](../plans/README.md), the router from the seat page's own **Run this** line. Nothing else went in.
- **The skill is pointed at, never rewritten.** Skills are folders in [skills/](../../skills/README.md) and they get pointed at, not duplicated — [engine.md](../engine.md) already says so.
- **KPI Current is empty on every page**, and empty means empty: not a guess, not a target, and not a 0, because a 0 is a figure and a figure reads as a measurement somebody took. Nobody took one.
- **Who fills a seat stays "not recorded."** The one recorded holder is the COO, and there is no COO pack in this folder.
- **No status stamp.** These pages carry no Assigned / Unassigned / Parked line. The status columns on [desks/README.md](../desks/README.md), [bodies/README.md](../bodies/README.md), and [plans/README.md](../plans/README.md) are the ones that carry status, and this folder changes none of them.
- **Named missing stays named.** Each page ends with the seat page's own named-missing list, unfilled.
- **[how-money-moves.md](../how-money-moves.md) goes on a Knowledge line only when that seat's own leftover names a money-move job.** Read against the leftovers as they stand today, none does, so the page is on no pack. It gets added to one when a leftover names one, and not before.
- **Nothing here sends, and no program GitHub.** [locks.md](../locks.md) is the list, and every pack opens it first.

## Who has a pack here

Forty-two leftover-file employees, plus the CTO. Forty-three pages.

**The COO pack is not in this folder.** It is being written on separate work, and this folder does not write it or stand in for it. That is why forty-two of the forty-three leftover-file employees are below rather than all forty-three.

**The CTO has a pack here and is still not one of the forty-three** — [leftovers/README.md](../leftovers/README.md) says that plainly, and this folder does not move it onto that list.

**Head of Engineering and Developer have no pack here.** Those two stay parked under the machine locks, exactly as they are in [leftovers/](../leftovers/README.md).

## How to use one

1. Read [locks.md](../locks.md). Every pack assumes you did.
2. Open your seat's pack above. Read the four parts in order: purpose, knowledge, skill, support.
3. Open the pages the Knowledge line names, then run the router the Skill line names. One pass, not two.
4. Run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md). Hand anything external to Michael. **Nothing sends.**

**If the corpus holds no expert material for a seat, that seat's pack says so and points at the leftover.** That is the finished page, not a failure — and it is the honest half of the pack, the same way "what is behind it today" is the honest half of a KPI.

Named gaps stay named. Full list: [SOURCES.md](../../SOURCES.md).
