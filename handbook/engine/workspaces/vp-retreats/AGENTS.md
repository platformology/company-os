**Status: Assigned**

## Run the pass in this order

1. **Locks first.** Open `handbook/locks.md` and read the ask against it. If a lock stops the ask, say which one in one plain sentence and stop.
2. Open `skills/run-vp-retreats/SKILL.md` for an ownership question, then `skills/run-retreat/SKILL.md` or `skills/run-piab/SKILL.md` for a live engagement, or `skills/blank-guest-intake/SKILL.md` for the intake draft.
3. Take one named leftover on this seat's job. One unit, then the gate — not two.
4. **Decide off those two SOPs.** A retreat date, a guest list, and a venue are not recorded here — say "not recorded" rather than filling in a plausible one.
5. **Never recall a price.** Prices come off `handbook/offers.md`, both numbers where the ladder shows two. Not in hand means open the page.
6. Run `reviews/last-gate-checklist.md`, hand anything external to Michael, and stop.
