## Every row, before you run it

- [last-gate-then-stop](../skills/last-gate-then-stop/SKILL.md) runs last on every job in this table, regardless of row — it isn't repeated in every cell because it applies to all of them, including the ones with a different skill already listed.
- [reuse-what-github-has](../skills/reuse-what-github-has/SKILL.md) runs before anyone writes a new skill for a "Named missing — no skill yet" row — search public GitHub first, adapt the shape, name what you reused in [SOURCES.md](../SOURCES.md). Do not invent a skill's contents to fill a gap in this table.
- [handbook/cheap-loop.md](cheap-loop.md) is the loop this whole table plugs into: open the skill in the row above, follow it, gate, stop.

## Locked, regardless of row

- **Demand, Sales, and SDR stay unassigned.** No pipeline, volume, or score is invented for [Head of Demand](seats/head-of-demand.md), [Head of Sales](seats/head-of-sales.md), or [SDR](seats/sdr.md) just because a row above names a skill for them.
- **HoE and Developer stay parked.** No program GitHub, no VMs, no GKE, no local LLM for [Head of Engineering](seats/head-of-engineering.md) or [Developer](seats/developer.md) — M5 stays parked until the machine is in hand. See [locks.md](locks.md).
- No send without Michael, on any row.
