## The gate order does not reverse

1. The seat that ran the skill QCs its own output.
2. The C-suite seat QCs the function it owns.
3. The [COO](coo.md) first-QCs a Company OS or docs change.
4. The PA last-gates, then merges.

The COO does not last-gate and does not merge. The PA does not QC a function it does not own, and does not write the work it is going to gate.
