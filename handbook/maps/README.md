# handbook/maps/ — the company map and the C-suite division maps

**Written: 21 Aug 2026** · **Research: not closed**

Two kinds of page live here. One company map the COO opens to see the whole company. One division map per C-suite function, so each C-suite seat can be held to its own division result.

A map holds no new fact. Every line points at the page that already recorded it. When a map and a seat page disagree, **the seat page wins**, and the map is what gets fixed.

| Map | What it holds | Open it when |
|---|---|---|
| [company.md](company.md) | The business map, the four-level architecture, the money-move pipeline, and the one plan the COO runs | Before any first QC, and before holding a C-suite seat to anything |
| [coo.md](coo.md) | First QC, the leftover write assigned to Claude / Qwen, the C-suite held to their maps | Sitting the COO seat |
| [cmo.md](cmo.md) | Positioning and the public offer ladder | A change lands in the marketing function |
| [cso.md](cso.md) | Pipeline, offer fit, close | A change lands in the sales function |
| [cfo.md](cfo.md) | How money moves through the LLC and its two DBAs | A change lands in the finance function |
| [cco.md](cco.md) | Author success, campaign QA, retreat experience | A change lands in the customer function |
| [cto.md](cto.md) | The locks, and L3 efficiency | A change reaches for a machine, a stack, or a program repo |
| [chro.md](chro.md) | Who is on the roster and how they are classified | A change touches the roster |
| [pa.md](pa.md) | The daily loop and the last gate | A change is ready for the gate |

Every division map carries the same five rows: which seats report into that function, which money-move job it owns, the KPI names already on [plans/README.md](../plans/README.md), the leftover-today already on each seat's leftover file, and how those KPI names tie to the COO's two.

## What a map is not

| | |
|---|---|
| **Not a leftover file** | Leftovers live in [leftovers/](../leftovers/README.md). This folder does not restate one, recut one, or write a new one. |
| **Not a pipeline** | Leftover-file employee pipelines live in `handbook/pipelines/` — three or more per employee, incoming, leftover-today, outgoing/QC, named holes as child stages. Another PR owns that folder. Not rewritten here, and not a forecast. |
| **Not a seat page, plan, body, desk, or pass** | Those hold the standing facts and the pass. A map is the view across them. |
| **Not evidence a seat is staffed** | Who fills stays not recorded except COO. A map existing for a function fills nothing. |
| **Not a KPI board** | KPI names are copied from [plans/README.md](../plans/README.md) as names. **Current stays empty** — not a guess, not a target, not a 0. |

## Read one

1. Read [locks.md](../locks.md).
2. Open [company.md](company.md).
3. Open the division map for the function in front of you.
4. Do the thing that map already names. If it says not recorded, say not recorded and stop.
5. Run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) before anything goes external. **Nothing sends.**

Named missing stays named. Research is not closed.
