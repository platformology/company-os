# Cheap loop

Shape: the trigger → policy → tools → gate → learning loop from [dswh/company-os](https://github.com/dswh/company-os) `departments/_canvas-template.md` — already the source for [weekday-loop.md](weekday-loop.md) and [how-money-moves.md](how-money-moves.md). The token-cheap discipline below is adapted from [0xdarkmatter/claude-mods](https://github.com/0xdarkmatter/claude-mods), `skills/loop-ops/references/state-spine.md` ("the cheapest lever is cadence... put the cheap model on the maker, reserve the expensive one for the gate decision") and [Oruga420/claude-code-skills](https://github.com/Oruga420/claude-code-skills), `loop-builder/SKILL.md` (the zero-work-run question) — inverted here, since at Platformology an empty queue is not a clean win. Full attribution: [SOURCES.md](../SOURCES.md).

This is the page every Grok Bot seat — and every human picking up a job — opens before opening anything else. It is deliberately short. A long loop is an expensive loop.

## The rule

1. **Open the matching `SKILL.md`** for the job in front of you. See [seat-job-map.md](seat-job-map.md) to find it — the first skill in your seat's row is that seat's router, and it points at everything else the seat runs.
2. **Follow it.** Each skill points at the real Notion SOP; this repo does not restate it, and neither do you.
3. **Run [last-gate-then-stop](../skills/last-gate-then-stop/SKILL.md)** — [reviews/last-gate-checklist.md](../reviews/last-gate-checklist.md), every line, honestly.
4. **Stop.** Hand off to Michael for anything that ships. Don't keep working past the gate "to be helpful" — that's where an expensive loop starts.

That's the whole loop. One skill, one gate, one stop. A bot re-deriving facts from scratch every pass is the expensive failure mode here, not the safe one.

## Do not re-derive facts

If [offers.md](offers.md), [clients.md](clients.md), or [people.md](people.md) already answers the question, use that answer. Don't work backward from a Notion page, a folder name, or a plausible guess to reconstruct a fact this repo already states, and don't spend a pass "double-checking" a sourced fact against your own memory.

## Never invent

- Never invent a client, a dollar figure, a person, or a price. See [locks.md](locks.md), [offers.md](offers.md), [clients.md](clients.md), [people.md](people.md).
- Never invent a Current number. **KPI Current stays empty** — 0 Current, 0 Prospect, per the 18 Aug 2026 extract in [clients.md](clients.md).
- If a price comes up mid-loop, don't recall it — run [place-on-offer-ladder](../skills/place-on-offer-ladder/SKILL.md), which quotes both numbers where the ladder shows two and says "no public price" for Platinum Major List.

## Humans are not 24/7. Bot seats are.

Jhana, Bob, and Anthony are not 24/7 — see [people.md](people.md). A Grok Bot seat is. That asymmetry is why this page exists: a bot seat left without a cheap, honest loop will either sit idle or invent work to look busy. Both are failures. This page is the third option.

## Empty queue is a failure

[Oruga420/claude-code-skills](https://github.com/Oruga420/claude-code-skills) `loop-builder/SKILL.md` treats "nothing to do → clean stop" as the win condition for a generic loop. Platformology inverts that: for a Grok Bot seat, idle is a failure state, not a finish line — humans are not 24/7, bot seats are.

**When a named job's queue is empty, the next unit of work is:** learn or improve that same named job, drawn from a named corpus gap already listed in [SOURCES.md](../SOURCES.md) — never a new job, a new client, a new offer, or a new KPI. Example: if the queue behind `author-support-reply` is empty, the next pass rereads the FAQ gate for a gap already named there, or tightens the skill's own steps against a real past reply. It does not go find a new client to message.

## Never

- Never skip straight to work without opening the matching `SKILL.md` first.
- Never invent a new job because the named one ran dry — see "Empty queue is a failure" above.
- Never treat a human seat's off-hours as a bot seat's off-hours, or the reverse.
- Never send anything without Michael. See [locks.md](locks.md).
