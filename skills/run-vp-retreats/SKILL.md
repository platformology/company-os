# Run VP Retreats

Reused from: [narrative-io/narrative-skills-marketplace](https://github.com/narrative-io/narrative-skills-marketplace), `docs/authoring-skills.md` ("never duplicate" the reference in the skill body), and [dzhng/skills](https://github.com/dzhng/skills), `skills/authoring/write-skills/SKILL.md` ("keep a single source of truth"). Seat framing from [holacracyone/Holacracy-Constitution](https://github.com/holacracyone/Holacracy-Constitution), `Holacracy-Constitution.md` (Role = Purpose + Domains + Accountabilities), and [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` (a seat is independent of, and can be vacant of, its holder).

## The seat
[handbook/seats/vp-retreats.md](../../handbook/seats/vp-retreats.md) is the repo-side page for this seat — purpose, what it owns, what it reports, and what's named missing. Open it first. **Who currently fills the seat is not recorded** — see [handbook/people.md](../../handbook/people.md). Don't name a holder to make the answer look complete; route the decision to Michael.

## The gate
Two Notion pages this seat owns; this repo does not restate either:
- [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5) — how a live Book Retreat actually runs.
- [PIAB SOP](https://app.notion.com/p/3c125e30d68b81d5beecda81a111e6b3) — how a Platform in a Box engagement actually runs.

The [blank guest intake draft](https://app.notion.com/p/3c125e30d68b812486c8eac90777658c) (Notion) also sits with this seat. Whatever is blank there stays blank here.

## What this is not
**VP Retreats is not Retreat Producer.** They are two seats. VP Retreats owns the Retreat SOP and the PIAB SOP and decides how delivery runs; [Retreat Producer](../../handbook/seats/retreat-producer.md) reports into that seat and produces each individual retreat. Don't collapse them, and don't answer an ownership question by naming whichever seat is closer to hand.

- Producing or checking on a live Book Retreat → [run-retreat](../run-retreat/SKILL.md).
- Running or checking on a Platform in a Box engagement → [run-piab](../run-piab/SKILL.md).
- Working the guest intake form → [blank-guest-intake](../blank-guest-intake/SKILL.md).

## Steps
1. Open [handbook/seats/vp-retreats.md](../../handbook/seats/vp-retreats.md) — confirm the question actually belongs to this seat and not to Retreat Producer.
2. Open the [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5) or the [PIAB SOP](https://app.notion.com/p/3c125e30d68b81d5beecda81a111e6b3) in Notion, whichever the question is about. This repo does not restate either — link them, don't copy them.
3. **Do not invent a retreat date, guest list, or venue.** None of those is sourced in this repo; check the SOP and the live guest records in Notion instead of filling in a plausible one.
4. **Do not invent a PIAB cycle time.** Current cycle time is named missing — if asked how long an engagement takes, say it isn't written down.
5. Dietary, rooming, arrival, AV, and incident fields stay named missing — see [blank-guest-intake](../blank-guest-intake/SKILL.md). Not blanks to fill from a guess or from a comparable retreat's form.
6. Quote prices only from [handbook/offers.md](../../handbook/offers.md). Where the ladder shows two numbers, quote both and pick neither.
7. Before anything from this seat goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never restate the Retreat SOP or the PIAB SOP in this repo — link them, don't copy them.
- Never treat VP Retreats and Retreat Producer as the same seat.
- Never invent a retreat date, guest list, or venue.
- Never invent a PIAB cycle time.
- Never fill a dietary, rooming, arrival, AV, or incident field from a guess.
- Never name a holder for this seat — it isn't recorded.
- Never quote a price not on [handbook/offers.md](../../handbook/offers.md).
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
