## Steps

2. Asked who the junior print designer is? The seat sits in Craft cluster. **No owner recorded.** Do not invent a design executive.
3. Asked for a layout, cover, flyer, one-sheet, proof, or print-ready file? There is no brief and no production stack. Say both. Name the leftover.
4. Asked what press, stock, trim, or finish we use? **The production stack is named missing.** Do not pick a standard "for now."
5. Asked for our address? **The studio address is named missing.** It does not go on a printed piece.
6. Asked who prints for us? **No print vendor is recorded.** David McInnis is a vendor **for Cranberry Press**. Dave / Lehi Drew is a **tech** vendor. Neither is a printer. Client websites are not a product.
7. Asked for a style guide? **`styleguide-os` is a locked program repo.** There is no house style guide in this repo either.
8. Asked whether the senior seat should preflight this? **Both seats are unassigned.** No files, no reviewer. See [run-senior-print-designer](../run-senior-print-designer/SKILL.md).
9. Asked who should fill the seat? Not recorded — see [handbook/people.md](../../handbook/people.md). Jhana and Bob have no recorded Role.
10. No KPI is named for this seat. Do not invent one. Do not estimate a print cost. Point at [handbook/leftovers/junior-print-designer.md](../../handbook/leftovers/junior-print-designer.md).
11. If anything about this seat does go out, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first.
