# Last-gate then stop

Reused from: [dswh/company-os](https://github.com/dswh/company-os), `reviews/README.md` and `reviews/comms-checklist.md` (the quality-gate-folder pattern), and [andreaswasita/copilot-cowork-dojo](https://github.com/andreaswasita/copilot-cowork-dojo), `skills/shipping-the-deliverable/SKILL.md` (the "last gate before it ships" framing: "if it fails any check, it doesn't ship").

## When to use this
The last step before anything leaves your hands — an email, a Sales Menu quote, a Notion edit, a repo change.

## Steps
1. Open [`reviews/last-gate-checklist.md`](../../reviews/last-gate-checklist.md).
2. Read every line as if you were reading it out loud to Anthony, Jhana, or Bob. If any of those three couldn't follow a line and act on it, the checklist failed — not them. Say so and stop; don't ship a page only a bot can run.
3. Check every box honestly. No box gets checked because "it's probably fine."
4. **All boxes checked** — stop here. Do not send it yourself. Hand it to Michael. See [`handbook/locks.md`](../../handbook/locks.md): no send without Michael.
5. **Any box unchecked** — stop here too. Fix the draft, or flag the specific unchecked line to Michael. Do not soften the checklist to make the draft pass.

## Never
- Never skip a line because you're in a hurry — the checklist exists because of the hurry.
- Never add a second checklist, a scorecard, or a stamp on top of this one. One checklist, one honest read, then stop.
- Never mark a line passed on behalf of a fact you didn't personally check.
