# Run the Book Copy Writer seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/book-copy-writer.md](../../handbook/seats/book-copy-writer.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No book, title, or description exists here to write around. Any price that shows up in book copy comes from [offers.md](../../handbook/offers.md) and nowhere else.

## Steps

1. Open [handbook/seats/book-copy-writer.md](../../handbook/seats/book-copy-writer.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [Book Strategist](../../handbook/seats/book-strategist.md), which is unassigned too. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no book and no title. Say so, and do not draft a blurb from a working title somebody mentioned.
4. Asked what would have to exist first: say it plainly — who fills this seat; any book or title to write around.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent a claim, a blurb, an endorsement, or a review quote.
- Never quote a price outside [offers.md](../../handbook/offers.md), and quote both numbers where that ladder shows two.
- Never collapse the track record into one number — [quote-track-record](../quote-track-record/SKILL.md) quotes it with its dates.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
