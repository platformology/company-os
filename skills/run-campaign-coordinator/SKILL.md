# Run the Campaign Coordinator seat

Reused from: [narrative-io/narrative-skills-marketplace](https://github.com/narrative-io/narrative-skills-marketplace), `docs/authoring-skills.md` ("never duplicate" the reference in the skill body), and [dzhng/skills](https://github.com/dzhng/skills), `skills/authoring/write-skills/SKILL.md` ("keep a single source of truth"). Seat shape: [holacracyone/Holacracy-Constitution](https://github.com/holacracyone/Holacracy-Constitution), `Holacracy-Constitution.md` (a Role is its Purpose and Accountabilities), and [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` (a seat is independent of, and can be vacant of, its holder).

## When to use this
Someone asks what the Campaign Coordinator does, hands a day-to-day campaign step to that seat, or asks whether the Coordinator or VP Campaigns owns something. For actually running or checking on a live campaign, use [run-campaign](../run-campaign/SKILL.md) — this page is about the seat, not the campaign.

## The gate
Three pages define this seat, and this repo restates none of them:
- [handbook/seats/campaign-coordinator.md](../../handbook/seats/campaign-coordinator.md) — the seat itself: Purpose, what it owns, what it's locked out of.
- [Campaign Coordinator do-this (last-gated)](https://app.notion.com/p/3c125e30d68b8181aaece1c83104102d) (Notion) — owned by this seat, and the source of truth for its day-to-day steps.
- [Campaign SOP](https://app.notion.com/p/3c025e30d68b81ea99c0dcf96db7cd2e) (Notion) — owned by VP Campaigns, not by this seat.

## Who owns what
**Campaign Coordinator is not VP Campaigns — they are two seats.** VP Campaigns owns the [Campaign SOP](https://app.notion.com/p/3c025e30d68b81ea99c0dcf96db7cd2e); the Coordinator reports into that seat and runs the do-this page. **CMO does not own day-to-day either.** Read [handbook/seats/campaign-coordinator.md](../../handbook/seats/campaign-coordinator.md) alongside [handbook/seats/vp-campaigns.md](../../handbook/seats/vp-campaigns.md) and [handbook/seats/cmo.md](../../handbook/seats/cmo.md) before you assign anything, and don't collapse the three into one seat.

## Steps
1. Open [handbook/seats/campaign-coordinator.md](../../handbook/seats/campaign-coordinator.md) first — it tells you what this seat owns and where it stops.
2. Open the [Campaign Coordinator do-this](https://app.notion.com/p/3c125e30d68b8181aaece1c83104102d) page in Notion for the actual steps. This repo does not restate them, and work that isn't on that page isn't this seat's job.
3. When the question is how a campaign runs start to finish, go to the [Campaign SOP](https://app.notion.com/p/3c025e30d68b81ea99c0dcf96db7cd2e) and to VP Campaigns — that's their page, not this seat's.
4. **Who fills this seat is not recorded** — see [handbook/people.md](../../handbook/people.md). If asked, say it's not recorded; the seat's work stands whether or not a name is attached to it.
5. Quote prices only from [handbook/offers.md](../../handbook/offers.md).
6. Before anything from this seat goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md), then stop and hand off.

## Never
- Never restate the do-this page, the Campaign SOP, or the seat page in this repo — link them, don't copy them.
- Never treat Campaign Coordinator, VP Campaigns, and CMO as the same seat, and never hand day-to-day to the wrong one.
- Never name a holder for this seat, or invent a do-this step that isn't on the Notion page.
- Never quote a price not on [handbook/offers.md](../../handbook/offers.md).
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
