## Steps

1. Open [handbook/seats/book-strategist.md](../../handbook/seats/book-strategist.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [CCO](../../handbook/seats/cco.md), whose holder is not recorded either. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no book and no author. Say so, and do not sketch a positioning for a book nobody has named.
4. Asked what would have to exist first: say it plainly — who fills this seat; any book, author, or manuscript for the bench to work on.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent a book, an author, a thesis, an outline, or a title.
- Never read a folder name as a book, or a Past client as a live engagement.
- Never write the manuscript from this seat — that is the [Book Writer](../../handbook/seats/book-writer.md) seat, and it is unassigned too.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
