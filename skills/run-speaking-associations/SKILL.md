## Steps

1. Open [handbook/seats/speaking-associations.md](../../handbook/seats/speaking-associations.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [CMO](../../handbook/seats/cmo.md), whose holder is not recorded either. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no speaking calendar, no talk, and no fee. Say so, and do not assemble a list of associations that would probably book us.
4. Asked what would have to exist first: say it plainly — who fills this seat; any speaking calendar, event, talk title, or fee — none is recorded in this repo.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.
