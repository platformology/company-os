## The gate
The seat page is [handbook/seats/social-account-expert.md](../../handbook/seats/social-account-expert.md), and this skill does not restate it.

**This seat is unassigned.** There is no holder, no social handle, account, profile, page, or platform, and no live job for it to run today. That is the whole honest state of the seat. It reports to [Social Media Strategist](../../handbook/seats/social-media-strategist.md) on paper, and that seat is unassigned too.

This is one seat that would run one named account, not one seat per invented network. **A post is a send.** The line against Strategist is not recorded. Do not draw it.

## If you were sent here for work
There is none assigned. Say that plainly.

That is not a lookup failure or a page that hasn't been written yet — the seat has no accountabilities recorded because no source records any, and this repo does not write them in ahead of a source. Nothing here needs to be filled in, and no handle needs to be produced to make the answer look complete.

## Steps
1. Open [handbook/seats/social-account-expert.md](../../handbook/seats/social-account-expert.md) before answering anything.
2. Asked who runs the social accounts? The seat reports into Social Media Strategist and is unassigned — see [run-social-media-strategist](../run-social-media-strategist/SKILL.md). Don't hand the work up to Strategist.
3. Asked what our handles are? Not recorded. Do not guess, assemble, or "find" one.
4. Asked to post, reply, comment, like, follow, message, or schedule? No. A post is a send. No account is recorded to do it from.
5. Asked to connect a platform or add a scheduler? No sixth tool gets added. Slack is connected and no seat's job sources it — not a social channel.
6. Asked for follower counts, engagement, or a KPI? None is recorded. No KPI is named for this seat. Point at [handbook/leftovers/social-account-expert.md](../../handbook/leftovers/social-account-expert.md).
7. Asked whether this seat or Strategist owns something? The line is not recorded. Say that instead of picking.
8. Asked who should fill the seat? Not recorded, and not this skill's guess — see [handbook/people.md](../../handbook/people.md). Jhana and Bob have no recorded Role and don't get assigned one here.
9. If anything about this seat does go out, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first.

- Never invent a follower count, engagement figure, or KPI, including a 0.

- Never draw the line against Social Media Strategist.
