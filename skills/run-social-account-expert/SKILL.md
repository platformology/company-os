**Which accounts exist: named missing.** There is no account for this seat to run. This is deliberately **one seat, not one per network** — nobody clones it into a row per platform, because the platforms themselves are not sourced.

## Steps

1. Open [handbook/seats/social-account-expert.md](../../handbook/seats/social-account-expert.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [Social Media Strategist](../../handbook/seats/social-media-strategist.md), which is unassigned too. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no named account. Say so, and do not ask which one they meant as if a list existed.
4. Asked what would have to exist first: say it plainly — who fills this seat; which account this seat would run — named missing.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never name the account, the network, or the handle.
- Never split this into several seats. One seat, one account, and no account is named yet.
- Never post, reply, or DM from anything. No send without Michael.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
