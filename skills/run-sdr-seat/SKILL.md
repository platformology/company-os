# Run the SDR seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` (a seat exists independently of its holder and can be vacant), [seb1n/awesome-ai-agent-skills](https://github.com/seb1n/awesome-ai-agent-skills), `sales/lead-scoring/SKILL.md` (a fit/engagement scoring model — inverted here into a refusal, since Platformology has none), and [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins), `sales/skills/draft-outreach/SKILL.md` (research first, draft — never blast). All three are already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate
[handbook/seats/sdr.md](../../handbook/seats/sdr.md) is the seat page. This skill does not restate it — open it before doing anything.

**This seat is unassigned.** No extract names a holder. If you came here looking for assigned work, that's the honest answer: there isn't any yet.

## What is actually recorded
- **Purpose:** qualify inbound and keep the CRM honest.
- **Reports to:** [Head of Sales](../../handbook/seats/head-of-sales.md), also unassigned. See [run-sales](../run-sales/SKILL.md).
- **The CRM is Notion Clients** — [handbook/clients.md](../../handbook/clients.md). Not HubSpot. HubSpot is closed.
- **Owns:** nothing invented.

There is no lead list and no scoring model behind this seat. [campaign-lead-scoring](../campaign-lead-scoring/SKILL.md) already refuses to invent a model, and this seat does not get a different answer.

## Steps
1. Open [handbook/seats/sdr.md](../../handbook/seats/sdr.md).
2. If asked who qualifies inbound: the seat is unassigned, and so is the Head of Sales seat above it. Route the ask to Michael rather than to a name.
3. If asked for leads, a lead count, an inbound volume, or a conversion rate: **none exists in this corpus.** Say so. Do not assemble a list from folder names, past clients, or a Notion search.
4. If asked to score, rank, or tier a lead: there is no criterion, weight, or threshold to score against. Hand off to [campaign-lead-scoring](../campaign-lead-scoring/SKILL.md), which refuses on the same grounds — do not produce a number, an A/B/C tier, or an MQL/SQL cutoff.
5. If asked to keep the CRM honest: work in Notion Clients, and respect what [handbook/clients.md](../../handbook/clients.md) already settles — folder names are not clients, Hoffman is a question and not a Current client, and the Current client count is 0 on the 18 Aug 2026 extract, given with that date. The KPI "Current" is a different field and stays empty: no figure goes in it, and a 0 is a figure. Moving anyone to Current or Prospect is an ask-Michael-first item per [handbook/locks.md](../../handbook/locks.md).
6. If asked for outreach: draft only, personalized from something real, and it does not leave the building. Nothing goes to a prospect without Michael.
7. For any price that comes up on a qualifying call, quote only from [handbook/offers.md](../../handbook/offers.md) — both numbers where the ladder shows two, "no public price" for Platinum Major List. Use [place-on-offer-ladder](../place-on-offer-ladder/SKILL.md).
8. Before anything from this seat goes anywhere external, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md), then stop.

## Never
- Never restate the seat page here — link it.
- Never invent a lead, a lead list, a lead count, or an inbound volume.
- Never assign a lead score, a tier, or a qualification threshold — there is no model to score against.
- Never build a prospect list out of folder names or the 67 Past clients.
- Never record a client as Current or Prospect to make the CRM look busier.
- Never treat HubSpot as the CRM. It is closed.
- Never name a holder for this seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
