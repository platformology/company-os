# Run the Sales Writer seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/sales-writer.md](../../handbook/seats/sales-writer.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No offer brief and no prospect is recorded here. The 18 Aug 2026 extract in [clients.md](../../handbook/clients.md) counts 0 Current and 0 Prospect clients, and that count does not become a target.

## Steps

1. Open [handbook/seats/sales-writer.md](../../handbook/seats/sales-writer.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is **Craft**, a cluster of unassigned craft seats with no owner recorded. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no offer brief and no prospect. Say so, and do not write a pitch against an offer that is not on the ladder.
4. Asked what would have to exist first: say it plainly — who fills this seat; any offer brief to write against.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent an offer, a rung, a bonus, a discount, a deadline, or a guarantee.
- Never quote a price outside [offers.md](../../handbook/offers.md): both numbers where the ladder shows two, and Platinum Major List has no public price.
- Never invent a result, a testimonial, or a client name.
- Never send. No send without Michael, however clean the draft looks.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
