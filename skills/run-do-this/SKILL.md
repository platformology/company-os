# Run do-this

Reused from: [narrative-io/narrative-skills-marketplace](https://github.com/narrative-io/narrative-skills-marketplace), `docs/authoring-skills.md` ("never duplicate" the reference in the skill body), and [dzhng/skills](https://github.com/dzhng/skills), `skills/authoring/write-skills/SKILL.md` ("keep a single source of truth").

## The gate
The [Do this](https://app.notion.com/p/3c025e30d68b8142a971ccdb0d657b22) (Notion) page is the single source of truth for daily/standing work. This repo does not restate it — open it before doing anything.

## Steps
1. Open [Do this](https://app.notion.com/p/3c025e30d68b8142a971ccdb0d657b22) in Notion at the start of a session.
2. **Do not invent daily work** that isn't on that page — if it's not there, it's not today's job.
3. Before anything drawn from today's work goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never restate the Do this page in this repo — link it, don't copy it.
- Never invent a task, a client touch, or a piece of daily work that isn't on that page.
- Never send anything from today's work without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
