# Run the Book Writer seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/book-writer.md](../../handbook/seats/book-writer.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No manuscript, brief, author, or book is recorded here, and the strategist seat above this one is unassigned as well — so there is nothing to write and no brief to write it against.

## Steps

1. Open [handbook/seats/book-writer.md](../../handbook/seats/book-writer.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [Book Strategist](../../handbook/seats/book-strategist.md), which is unassigned too. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no book and no brief. Say so, and do not write a chapter to show willing — a draft written today becomes what somebody quotes tomorrow.
4. Asked what would have to exist first: say it plainly — who fills this seat; any book, brief, or author to write for.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never write a chapter, outline, or sample to have something to show.
- Never file invented text as corpus — that is the failure [run-content](../run-content/SKILL.md) exists to prevent, and nobody can tell 27 years from this afternoon once it is filed.
- Never write in a client's voice, or Michael's, and let it leave the building. No send without Michael.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
