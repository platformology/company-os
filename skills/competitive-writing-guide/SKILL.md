Reused from: [qa-aman/claude-skills](https://github.com/qa-aman/claude-skills), `skills/by-role/marketing/customer-persona/SKILL.md` — one file owns "the section order," everything else there is "Read only. ## The gate
The guide lives in Notion: [Competitive Writing Guide draft](https://app.notion.com/p/3c125e30d68b81239c5fc767bddc0823). It is a **draft, not a live campaign asset** — nothing in it ships to a client or the public without Michael.

## What this is
A writing guide for one **buying style**. The draft opens on writing copy for a person with a Competitive buying style — how that reader wants to be written to. "Competitive" names the reader, not a rival company.

The draft is a page of fields, not a two-style comparison. Head of Content sourced the five off the page: **Characteristics, Buying needs, Likes and dislikes, Use, Avoid.** Those five are the list. Don't look for a sixth, and don't add one.

## What this is not
- **Not a competitor teardown.** Don't compare Platformology to another company, and don't invent a rival, a feature, a price, or a claim. No such comparison is on the page, and none gets built here.
- **Not the client inbox.** A client's question is answered from the FAQ — [run-faq](../run-faq/SKILL.md), then [author-support-reply](../author-support-reply/SKILL.md), which drafts and never sends. Style guidance is not a reply.

## Steps
1. Open the [Competitive Writing Guide draft](https://app.notion.com/p/3c125e30d68b81239c5fc767bddc0823) before doing anything.
2. **Methodical field list:** copy the field names and their order exactly as they stand on that page. Don't reword them, don't reorder them, don't add a field. The page owns the list and the values already filled in against it, and this repo restates neither — read them there rather than working from memory.
3. **Competitive answers:** write the Competitive buying-style answer for each of those same fields, and only from a sourced extract Michael provides — persona quotes, a piece of sourced writing, a document or link he's handed you. Keep the source next to the words, the way the page already does.
4. **No extract for a field:** leave that field blank and write **"not sourced."** Not a guess, not a paraphrase of the field above it, not a line borrowed from another style.
5. **One style per page.** The draft says not to write other buying styles off it, so don't produce Spontaneous or Humanistic copy from this page.
6. **Training names stay in the old persona decks.** They aren't clients, and none of them moves onto a client list from here.
7. Never treat this guide as a live campaign — see [Campaign SOP](https://app.notion.com/p/3c025e30d68b81ea99c0dcf96db7cd2e) (Notion) for what's actually running.
8. Before anything drawn from this guide goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never write a Competitive answer from anything but a sourced extract — blank plus "not sourced" is the right answer.
- Never add, reword, or reorder a field on the Methodical list, and never invent a sixth field.
- Never turn this into a comparison against another company, and never invent a rival, a feature, a price, or a claim to fill a field.
- Never present this draft as a live campaign asset.
- Never quote a price not on [handbook/offers.md](../../handbook/offers.md).
- Never send anything drawn from this guide without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
