# Competitive writing guide

Reused from: [slgoodrich/agents](https://github.com/slgoodrich/agents), `plugins/ai-pm-copilot/skills/competitive-analysis-templates/SKILL.md` ("never fabricate competitor information... when data is unavailable, explicitly note it rather than inventing data").

## The gate
The guide lives in Notion: [Competitive Writing Guide draft](https://app.notion.com/p/3c125e30d68b81239c5fc767bddc0823). It is a **draft, not a live campaign asset** — nothing in it ships to a client or the public without Michael.

## Steps
1. Open the [Competitive Writing Guide draft](https://app.notion.com/p/3c125e30d68b81239c5fc767bddc0823) before doing anything.
2. **Methodical field list:** copy it exactly as it exists in the Notion page. Don't reword, reorder, or add fields to it.
3. **Competitive column:** fill it only from a sourced extract Michael provides — a document, a quote, a link he's handed you. If there's no extract for a given competitor or field, leave it blank and say "not sourced," not a guess.
4. Never treat this guide as a live campaign — see [Campaign SOP](https://app.notion.com/p/3c025e30d68b81ea99c0dcf96db7cd2e) (Notion) for what's actually running.
5. Before anything drawn from this guide goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never invent a competitor's feature, price, or claim to fill a blank Competitive cell.
- Never add a field to the Methodical list that isn't already on the Notion page.
- Never present this draft as a live campaign asset.
- Never send anything drawn from this guide without Michael. See [handbook/locks.md](../../handbook/locks.md).
