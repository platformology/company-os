## The gate
Two pages, in this order, before you do anything in this seat:
1. [handbook/seats/retreat-producer.md](../../handbook/seats/retreat-producer.md) — what the seat owns, and what it explicitly does not invent.
2. [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5) (Notion) — how a Book Retreat actually runs. This repo does not restate the SOP.

## Who owns what
**Retreat Producer is not VP Retreats — they are two seats.** [VP Retreats](../../handbook/seats/vp-retreats.md) owns the [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5) and the guest intake draft; [Retreat Producer](../../handbook/seats/retreat-producer.md) reports into that seat and produces each retreat. Don't collapse them, don't answer as the other one, and don't escalate a producer decision as if it were already VP Retreats' call.

**Who fills this seat is not recorded** — see [handbook/people.md](../../handbook/people.md). The seat's work is defined without a name attached to it; don't attach one.

## Steps
1. Open the seat page, then the [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5). The SOP is the instructions; this page is only the seat.
2. To actually run or check on a live retreat, use the [run-retreat](../run-retreat/SKILL.md) skill — it's the same SOP gate, from the engagement's side rather than the seat's.
3. **Do not invent a retreat date, a guest list, or a venue.** None of the three is sourced in this repo. Check the SOP and the live guest records in Notion; if they don't answer it, say it's not recorded.
4. Dietary, rooming, arrival, AV, and incident fields stay **named missing** until the Notion form says otherwise — see the [blank-guest-intake](../blank-guest-intake/SKILL.md) skill. Never fill one from a guess, a "typical" guest, or a comparable retreat.
5. Quote prices only from [handbook/offers.md](../../handbook/offers.md).
6. Quote the Book Retreat era track-record numbers as-is — 128 (Book Retreat era), later 130–131, per [handbook/company-facts.md](../../handbook/company-facts.md). Never average them into one number.
7. Before anything from this seat goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md), then stop and hand off.

## Never
- Never restate the Retreat SOP in this repo — link it, don't copy it.
- Never treat Retreat Producer and VP Retreats as the same seat, and never name a holder for either.
- Never invent a retreat date, guest list, or venue.
- Never fill a dietary, rooming, arrival, AV, or incident field from a guess.
- Never collapse the track-record numbers into a single figure.
- Never quote a price not on [handbook/offers.md](../../handbook/offers.md).
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
