## Steps

1. Open [handbook/seats/pendulum-wiki.md](../../handbook/seats/pendulum-wiki.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [Head of Content](../../handbook/seats/head-of-content.md), whose holder is not recorded either. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: whether a wiki exists at all is named missing. Say that, and do not start one to have somewhere to put the work.
4. Asked what would have to exist first: say it plainly — who fills this seat; whether a Pendulum wiki exists at all, and where it would live.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never write new Pendulum material and shelve it as corpus — the librarian rule holds here, see [run-content](../run-content/SKILL.md).
- Never name a wiki, a URL, or a platform.
- Never present Pendulum as the buyer packet, or let it stand in for the whole corpus.
- Never install a wiki, a site, or anything else. This repo is markdown: no VMs, no GKE, nothing installed.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
