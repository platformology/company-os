Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/book-conceptual-editor.md](../../handbook/seats/book-conceptual-editor.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

There is no manuscript to edit and no brief to edit it against.

## Steps

1. Open [handbook/seats/book-conceptual-editor.md](../../handbook/seats/book-conceptual-editor.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [Book Strategist](../../handbook/seats/book-strategist.md), which is unassigned too. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no manuscript. Say so, and do not review an idea somebody describes out loud as if it were a draft.
4. Asked what would have to exist first: say it plainly — who fills this seat; any manuscript or brief to edit against.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never rewrite an author's argument into your own.
- Never invent the brief you are editing against.
- Never confuse this pass with the line-level one ([Copy Editor](../../handbook/seats/copy-editor.md)) or the accuracy one ([Book Technical Editor](../../handbook/seats/book-technical-editor.md)). Three passes, three seats, all empty.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
