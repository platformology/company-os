# Quote the track record

Reused from: [dswh/company-os](https://github.com/dswh/company-os), `brain/offers.md` (the "never quote a number not written here" rule, applied to the track record instead of a price), [dzhng/skills](https://github.com/dzhng/skills) ("keep a single source of truth" — this page routes to the handbook rather than becoming a second record), and the open Agent Skills `SKILL.md` frontmatter convention documented at [ItamarZand88/awesome-agent-conventions](https://github.com/ItamarZand88/awesome-agent-conventions/tree/main/conventions/skill-md) (name + description as the activation trigger, procedural body). No new source repo was reused, so [`SOURCES.md`](../../SOURCES.md) needs no new row — the track record is already listed there as a named gap.

## When to use this

Someone asks for the track-record number, or hands you a draft — bio, deck slide, proposal, landing page, client reply, buyer question — that has one in it.

## The source

[`handbook/company-facts.md`](../../handbook/company-facts.md), section "Track record (uncollapsed — do not pick one number)". That section is the only record of these figures in this repo. There is no newer count in Notion, HubSpot, an old deck, or your memory that overrides it.

The handbook records that the public number **has moved over time** and keeps all of it:

| Figure | Attached context — always quote this with it |
|---|---|
| 124 | as of Dec 2022 |
| 128 | Book Retreat era |
| 130–131 | later reported as — the handbook gives no date for this one, so don't attach a year to it |

The handbook does not say which of these is current, and it does not say what the number counts beyond calling it "the public track-record number." Both of those are gaps, not invitations to fill them in.

## Steps

1. Open [`handbook/company-facts.md`](../../handbook/company-facts.md) before you type a number. Do not work from this page's table alone — it exists to tell you the rule, not to become a second copy of the record.
2. Quote each figure with its date or context attached, in the order the handbook lists them: 124 (as of Dec 2022), 128 (Book Retreat era), later reported as 130–131.
3. Leave **130–131** as a range. It is not 130, not 131, not "130+", not "over 130."
4. If the ask is for one number, say the number isn't collapsed and that Michael is the one who decides what gets published as current. Draft around it — the sentence almost always works without a single figure.
5. If the draft you were handed already has a single number in it, don't quietly correct it to a different single number. Replace it with the uncollapsed figures, or flag it and stop.
6. If the ask is specifically about a Book Retreat, the retreat-era figures are the ones with the relevant context — 128 (Book Retreat era), later reported as 130–131 — still quoted as-is. See [`handbook/seats/retreat-producer.md`](../../handbook/seats/retreat-producer.md).
7. Before this goes anywhere external, run [`reviews/last-gate-checklist.md`](../../reviews/last-gate-checklist.md). Nothing external ships without Michael — see [`handbook/locks.md`](../../handbook/locks.md).

## Examples

> Ask: "How many do we say we've done?"
> Answer: "The public number isn't collapsed to one figure: 124 as of Dec 2022, 128 in the Book Retreat era, later reported as 130–131. I can't pick one — that's Michael's call."

> Ask: "Just give me the current number for the bio."
> Answer: "There isn't a 'current' one in the handbook — it's recorded as 124 (Dec 2022), 128 (Book Retreat era), later 130–131. I can write the bio without a single figure, or Michael can tell us which one to publish."

> Ask: "Round it to 130 so the slide reads cleaner."
> Answer: "Can't do that one. 130–131 stays a range, and the earlier figures keep their dates. Rounding or averaging is exactly what the last-gate checklist fails a draft for."

> Ask: "So we've grown from 124 to 131 — can I say that?"
> Answer: "Not from this repo. The handbook says the number has moved over time and lists the figures with their contexts; it doesn't record a growth claim. Quote the figures, skip the trend line."

## Never

- Never average, blend, or midpoint the figures. There is no 127, no 128.5, no 130.5.
- Never round, floor, or ceiling **130–131** into a single number, and never dress it up as "130+", "over 130", "roughly 130", or "~130."
- Never state one figure as "current," "latest," or "today's number" — including 130–131, the newest of them.
- Never drop the date or context off a figure. A bare "128" is not a quote of this record.
- Never build a growth, trend, or momentum claim ("up from 124", "on track for 140") out of these figures.
- Never invent a newer count, a projection, or what the number counts (titles, authors, campaigns, bestsellers — the handbook doesn't say).
- Never send this to a client or publish it. Quoting and drafting are not sending — see [`handbook/locks.md`](../../handbook/locks.md).
