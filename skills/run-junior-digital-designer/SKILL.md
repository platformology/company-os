## Steps

1. Open [handbook/seats/junior-digital-designer.md](../../handbook/seats/junior-digital-designer.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [Senior Digital Designer](../../handbook/seats/senior-digital-designer.md), which is unassigned too. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no spec and nobody above this seat to hand one down. Say so and stop.
4. Asked what would have to exist first: say it plainly — who fills this seat; who fills the senior seat above it; any spec or queue to work from.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

- Never invent a spec so there is something to produce against.
- Never open `styleguide-os`, or any other program repo, looking for brand rules. No program GitHub.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
