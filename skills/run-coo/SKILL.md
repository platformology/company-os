A slice is sourced or it doesn't exist. Finish the pass before taking the next slice.

## First QC on the Company OS
The COO seat is the first quality check the Company OS gets — first, not only. It sits ahead of [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) and never replaces it.

- **No restamping locked pages.** A page covered by [handbook/locks.md](../../handbook/locks.md), or one already stamped, gets read — not re-stamped, re-approved, or re-blessed. A second stamp on top of an existing one is not QC.
- **Silent to Michael on QC.** A QC pass produces no ping, no message, no approval request. Michael hears about it only when QC fails in a way that blocks a sourced slice, or when the item is already on the ask-Michael-first list in [handbook/locks.md](../../handbook/locks.md) — the two unresolved Cornelia Choe Zoom URLs, an offer showing "both" numbers, a client's status, a Role for Jhana or Bob. Everything external still needs Michael's sign-off; that is the lock, not QC.

## Bots run 24/7. Humans do not.
The cycle is continuous for a bot seat and is not continuous for a person. Do not plan a slice whose next step needs Michael, Anthony as a person, Jhana, or Bob to answer outside their hours. Silence off-hours is silence — not approval, not a reason to escalate, not a reason to proceed. Park the slice and pick it up when the human is on.

## Steps
1. Open [handbook/seats/coo.md](../../handbook/seats/coo.md) and [Grok Bot staff](https://app.notion.com/p/3c125e30d68b81dc9116e2e62b47f143) before working the seat.
2. Check [handbook/locks.md](../../handbook/locks.md). The COO seat is not an exception to any line on it.
3. Planning — take one sourced slice off [Do this](https://app.notion.com/p/3c025e30d68b8142a971ccdb0d657b22). If it isn't there, it isn't today's job.
4. Meetings — work what's already scheduled. Don't invent a meeting, an attendee, or a Zoom URL.
5. Execution — hand the slice to the skill that owns it: [run-campaign](../run-campaign/SKILL.md), [run-retreat](../run-retreat/SKILL.md), [run-uncovery](../run-uncovery/SKILL.md), [run-piab](../run-piab/SKILL.md), [run-money-moves](../run-money-moves/SKILL.md), [author-support-reply](../author-support-reply/SKILL.md).
6. Optimizing — run the QC pass above: first check, no restamping, silent to Michael.
7. Before anything from the pass goes anywhere external, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md), then stop and hand it to Michael — see [last-gate-then-stop](../last-gate-then-stop/SKILL.md).
8. Only then, the next sourced slice.

## Never
- Never invent COO work, an accountability, a KPI, or a deliverable. The public title is what's sourced; the rest is named missing.
- Never fan out — no parallel slices, no side work spun off mid-pass, no widening the slice because the phase felt short.
- Never restate [handbook/seats/coo.md](../../handbook/seats/coo.md), the Notion pages, or an SOP in this skill — link them.
- Never restamp a locked or already-stamped page.
- Never ping Michael to report a routine QC pass.
- Never run a human on a bot's clock, or read off-hours silence as a yes.
- Never send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
