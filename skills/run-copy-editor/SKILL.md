## Steps

1. Open [handbook/seats/copy-editor.md](../../handbook/seats/copy-editor.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is **Craft**, a cluster of unassigned craft seats with no owner recorded. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no copy queue and no recorded style guide. Say so, and do not invent a house rule while editing.
4. Asked what would have to exist first: say it plainly — who fills this seat; the style guide or voice document this seat would edit against — none is recorded here.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent a style rule and enforce it as this company's.
- Never open `styleguide-os`, or any other program repo, to go find one. No program GitHub.
- Never sharpen a claim while editing — an edit that strengthens a claim is a new claim.
- Never mark anything "ready to send." That is Michael's line, not an editor's.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
