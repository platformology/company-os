# Run money moves

Reused from: [narrative-io/narrative-skills-marketplace](https://github.com/narrative-io/narrative-skills-marketplace), `docs/authoring-skills.md` ("never duplicate" the reference in the skill body), and [dzhng/skills](https://github.com/dzhng/skills), `skills/authoring/write-skills/SKILL.md` ("keep a single source of truth").

## The gate
Two sources run money at Platformology; this skill does not restate either:
- [How money moves](https://app.notion.com/p/3c125e30d68b81b49524fe7bc9f65c81) (Notion) — the live process.
- [handbook/how-money-moves.md](../../handbook/how-money-moves.md) — the five jobs a coordinator runs: Attract, Diagnose, Place, Deliver, Expand alumni.

## Steps
1. Open both of the above before doing anything.
2. Figure out which of the five jobs applies, and follow that job's row in [handbook/how-money-moves.md](../../handbook/how-money-moves.md) for where to go next.
3. **Blue Sky stays off the LLC books.** See [handbook/company-facts.md](../../handbook/company-facts.md) and [handbook/locks.md](../../handbook/locks.md).
4. **Do not invent an invoice, an AR figure, or a savings total** — none of those is sourced in this repo.
5. Before anything drawn from a money job goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never restate the "How money moves" Notion page in this repo — link it, don't copy it.
- Never invent an invoice, an accounts-receivable figure, or a savings total.
- Never let Blue Sky touch the LLC books.
- Never quote a price not on [handbook/offers.md](../../handbook/offers.md).
- Never send anything from a money job without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
