# skills/ — jobs a new hire can run

Each folder here is one `SKILL.md`: a short, human page for one job, adapted from a public GitHub pattern. Every pattern is credited in [`SOURCES.md`](../SOURCES.md), and named in the file itself except where that would push the usable part of the page below the fold — then it goes at the bottom, or to `SOURCES.md` alone. No stamp stacks, no bot jargon — if Anthony, Jhana, or Bob can't run the page, the page failed.

Every folder in this directory has a row below. If you find a folder that isn't on this table, that's a bug in the table, not a skill you're allowed to skip.

Two kinds of page live here, and the **Kind** column tells you which one you're opening:

- **Seat router** — the page for a seat. It points at that seat's handbook page and hands you off to the job pages beside it. All twenty-three seats have one. Open the router when you're sitting in a seat and want to know what it owns.
- **Job** — the page for one piece of work: quoting a price, drafting a client reply, running a campaign. Open it when you know the task and need the safe way to do it.

Five pages run on everything regardless of seat; they're marked as such and sit at the top. Two of them bracket every other page here: `check-locks` before you act, `last-gate-then-stop` before anything leaves your hands.

If you'd rather start from your seat than from the job, open [handbook/seat-job-map.md](../handbook/seat-job-map.md) — same skills, indexed by seat.

## Where to start

Start with [check-locks](check-locks/SKILL.md) and [last-gate-then-stop](last-gate-then-stop/SKILL.md). One runs before you act, the other before anything leaves your hands, and between them they're the reason the rest of these skills are safe to run without Michael in the room for every keystroke.

Then read [run-do-this](run-do-this/SKILL.md), because it tells you what today's work actually is. Those three cover most of a first day.

## When a new skill lands

Add its row to the table above in the same commit that adds the folder, and add whatever you reused to [`SOURCES.md`](../SOURCES.md). A skill nobody can find from this page may as well not exist — that's the failure this index is here to prevent. [reuse-what-github-has](reuse-what-github-has/SKILL.md) is the page that tells you how to write the skill itself.
