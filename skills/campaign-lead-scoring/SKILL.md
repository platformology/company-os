# Campaign lead scoring

Reused from: [seb1n/awesome-ai-agent-skills](https://github.com/seb1n/awesome-ai-agent-skills), `sales/lead-scoring/SKILL.md`, and [sales-skills/sales](https://github.com/sales-skills/sales), `skills/sales-lead-score/SKILL.md` — both describe how to build a fit/engagement scoring model. Platformology's corpus has no such model, so this skill inverts their guidance into a refusal to invent one, not a builder.

## The gate
The draft lives in Notion: [Campaign lead scoring draft](https://app.notion.com/p/3c125e30d68b81f89125cfbbe398c770). **The corpus has no scoring model.** This skill does not build one, tune one, or assign a number to a lead.

## Named missing
Five fields on the draft stay named missing — this repo does not name them beyond "five fields," since naming them here would itself be inventing structure that the Notion page owns. Open the Notion page to see which five.

## Steps
1. Open the [Campaign lead scoring draft](https://app.notion.com/p/3c125e30d68b81f89125cfbbe398c770) before doing anything.
2. If asked to score a lead: there is no criterion, no weight, and no threshold to score it against. Say so.
3. If asked to build or propose a model: that's a decision for Michael, not something this skill drafts on its own. Flag the request; don't produce a point table, a tier system, or an MQL/SQL cutoff.
4. If a field on the draft is blank, it stays blank — named missing, not filled in from a comparable company's model or a generic 100-point template.
5. Before anything drawn from this draft goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never invent a scoring criterion, a weight, or a threshold.
- Never assign a lead a numeric score against a model that doesn't exist.
- Never fill one of the five named-missing fields with a guess.
- Never send anything drawn from this draft without Michael. See [handbook/locks.md](../../handbook/locks.md).
