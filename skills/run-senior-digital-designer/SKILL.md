# Run the Senior Digital Designer seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/senior-digital-designer.md](../../handbook/seats/senior-digital-designer.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No brief, no queue of digital work, and no recorded brand or style rules exist here to design against. `styleguide-os` is on the program GitHub list and stays locked, so it is not where anyone goes to find them.

## Steps

1. Open [handbook/seats/senior-digital-designer.md](../../handbook/seats/senior-digital-designer.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is **Craft**, a cluster of unassigned craft seats with no owner recorded. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no brief and no recorded brand rule to design against. Say so, and do not produce a rough version to be helpful — a rough version becomes the standard the moment somebody files it.
4. Asked what would have to exist first: say it plainly — who fills this seat; the brand and style rules this seat would design against — none is recorded here, and `styleguide-os` is a locked program repo, not a source; any queue of digital work.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never open `styleguide-os`, or any other program repo, looking for brand rules. No program GitHub.
- Never invent a palette, a typeface, a logo rule, or a template and file it as this company's.
- Never design a client-facing asset off a folder name or a guess at what the campaign is.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
