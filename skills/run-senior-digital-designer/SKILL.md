## The gate
The seat page is [handbook/seats/senior-digital-designer.md](../../handbook/seats/senior-digital-designer.md), and this skill does not restate it.

**This seat is unassigned.** There is no holder, no brief, no recorded junior / senior split, and no live job for it to run today. That is the whole honest state of the seat.

## If you were sent here for work
There is none assigned. Say that plainly.

The leftover job file on the M1 is not in this repo and is not restated here. A senior designer's specific temptation is a system. Nothing here needs a foundations document, and no palette needs to be defined to make the answer look complete.

## Steps
1. Open [handbook/seats/senior-digital-designer.md](../../handbook/seats/senior-digital-designer.md) before answering anything.
2. Asked who the senior digital designer is? The seat sits in Craft cluster. **No owner recorded.** Do not invent a design executive.
3. Asked to "just set the foundations" — a palette, a type scale, a component set, a brand book? **No.** Name the decisions that are missing and say they are Michael's. That is the largest invention available in this slice.
4. Asked for a mockup, template, or graphic? There is no brief. Say so and name the leftover.
5. Asked to audit existing assets for consistency? There is nothing to audit them against. Do not write the standard and then audit against it.
6. Asked to brief, review, or sign off the junior seat? **Both seats are unassigned.** There is no work and no relationship. See [run-junior-digital-designer](../run-junior-digital-designer/SKILL.md).
7. Asked what tools we use? **The five connected tools are Notion, Gmail, Google Calendar, Slack, and Google Drive.** No sixth gets added. Nothing in this repo installs software.
8. Asked who should fill the seat? Not recorded — see [handbook/people.md](../../handbook/people.md). Jhana and Bob have no recorded Role.
9. No KPI is named for this seat. Do not invent a consistency score. Point at [handbook/leftovers/senior-digital-designer.md](../../handbook/leftovers/senior-digital-designer.md).
10. If anything about this seat does go out, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first.

## Never
- Never name a Senior Digital Designer. The seat is unassigned.
- Never define a design system, component library, palette, type scale, grid, spacing scale, usage rule, or brand book.
- Never produce a mockup, wireframe, graphic, template, icon, or logo.
- Never invent the junior / senior split, and never brief, review, or sign off the other seat's work.
- Never invent an accountability or KPI for this seat.
- Never add a sixth connected tool or name a design application as installed.
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
