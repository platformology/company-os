## The gate
The seat page is [handbook/seats/copy-writer.md](../../handbook/seats/copy-writer.md), and this skill does not restate it.

**This seat is unassigned.** There is no holder, no brief, no audience, no channel, and no live job for it to run today. That is the whole honest state of the seat. It sits in Craft cluster. No owner is recorded.

This is not [Sales Writer](../../handbook/seats/sales-writer.md), Book Copy Writer, Book Writer, or [Head of Content](../../handbook/seats/head-of-content.md).

## If you were sent here for work
There is none assigned. Say that plainly.

That is not a lookup failure or a page that hasn't been written yet — the seat has no accountabilities recorded because no source records any, and this repo does not write them in ahead of a source. Nothing here needs to be filled in, and no sentence needs to be produced to make the answer look complete.

## Steps
1. Open [handbook/seats/copy-writer.md](../../handbook/seats/copy-writer.md) before answering anything.
2. Asked who writes copy? The seat sits in Craft cluster, no owner recorded, and is unassigned. Don't hand the work to Sales Writer, Book Copy Writer, Book Writer, or Head of Content.
3. Asked for a headline, landing page, email, ad, subject line, tagline, or one-pager? There is no brief, no audience, and no channel. Say so. Do not write a rough version to start from.
4. Asked for lead-magnet copy? The lead magnet has **no Offers row** — see [handbook/offers.md](../../handbook/offers.md) — and does not get a price or a description from here.
5. Asked to write an ICP, a persona, or a positioning statement? Not this seat, and not from a template. Personas belong to the corpus and to [Persona Architect](../../handbook/seats/persona-architect.md), which is unassigned too.
6. Asked who should fill the seat? Not recorded, and not this skill's guess — see [handbook/people.md](../../handbook/people.md). Jhana and Bob have no recorded Role and don't get assigned one here.
7. If anything about this seat does go out, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first.

## Never
- Never name a Copy Writer. The seat is unassigned.
- Never write a headline, landing page, email, ad, subject line, tagline, one-pager, or lead magnet.
- Never invent a brief, an audience, a channel, an ICP, a persona, or a KPI.
- Never write into the Competitive Writing Guide draft from this seat.
- Never price the lead magnet or add a row to [handbook/offers.md](../../handbook/offers.md).
- Never quietly reassign this seat's work to Head of Content, Sales Writer, or Book Copy Writer.
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
