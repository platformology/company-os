## The gate

[handbook/seats/copy-writer.md](../../handbook/seats/copy-writer.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No brief, campaign, or queue of copy is recorded here. Nothing this seat wrote would go out on its own either: no send without Michael.

## Steps

1. Open [handbook/seats/copy-writer.md](../../handbook/seats/copy-writer.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is **Craft**, a cluster of unassigned craft seats with no owner recorded. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no brief and no queue. Say so, and do not knock out a draft to be useful.
4. Asked what would have to exist first: say it plainly — who fills this seat; any brief or queue of copy.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent a claim, a testimonial, a case study, or a statistic.
- Never quote a price outside [offers.md](../../handbook/offers.md), and quote both numbers where that ladder shows two.
- Never collapse the track record into one number — [quote-track-record](../quote-track-record/SKILL.md) is the page for it.
- Never file new copy as corpus.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
