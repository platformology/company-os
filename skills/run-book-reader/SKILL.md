# Run the Book Reader seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/book-reader.md](../../handbook/seats/book-reader.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

There is no manuscript to read.

## Steps

1. Open [handbook/seats/book-reader.md](../../handbook/seats/book-reader.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [Book Strategist](../../handbook/seats/book-strategist.md), which is unassigned too. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no manuscript. Say so, and do not describe how a reader would probably feel about a book nobody has written.
4. Asked what would have to exist first: say it plainly — who fills this seat; any manuscript to read.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent a reader, a reaction, a test group, or a quote.
- Never turn a read into a rewrite — that is two other seats, both empty.
- Never let a read become a testimonial. Nothing goes public without Michael.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
