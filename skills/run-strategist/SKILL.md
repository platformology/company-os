# Run the Strategist seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/strategist.md](../../handbook/seats/strategist.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No brief, campaign, or piece of work is recorded here waiting on a strategy.

## Steps

1. Open [handbook/seats/strategist.md](../../handbook/seats/strategist.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is **Craft**, a cluster of unassigned craft seats with no owner recorded. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no brief and no piece of work. Say so, and do not produce a strategy deck for a job nobody has named.
4. Asked what would have to exist first: say it plainly — who fills this seat; any brief or piece of work to be strategist for.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent a goal, an audience, or a number to make a strategy look finished.
- Never write the copy from this seat — that is [Copy Writer](../../handbook/seats/copy-writer.md) and [Sales Writer](../../handbook/seats/sales-writer.md), both unassigned.
- Never invent an offer or a rung. Prices and rungs come from [offers.md](../../handbook/offers.md).
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
