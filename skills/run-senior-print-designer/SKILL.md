## The gate

[handbook/seats/senior-print-designer.md](../../handbook/seats/senior-print-designer.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No book, manuscript, title, trim size, or print vendor is recorded here. A folder name is not a book, and the 18 Aug 2026 extract in [clients.md](../../handbook/clients.md) counts 0 Current clients.

## Steps

1. Open [handbook/seats/senior-print-designer.md](../../handbook/seats/senior-print-designer.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is **Craft**, a cluster of unassigned craft seats with no owner recorded. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no book, no manuscript, and no spec. Say so, and do not mock one up from a title somebody said out loud.
4. Asked what would have to exist first: say it plainly — who fills this seat; any book, manuscript, trim size, or print vendor to design for.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent a title, a trim size, a page count, a paper stock, or a print vendor.
- Never read a folder name as a book, or a past client as a live one.
- Never open `styleguide-os`, or any other program repo, looking for design rules. No program GitHub.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
