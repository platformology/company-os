## If you were sent here for work
There is none assigned. Say that plainly.

The leftover job file on the M1 is not in this repo and is not restated here. A senior print designer's value is settling production. Closing the stack here means inventing the manufacturing decisions of the company. The gap stays named until Michael sources it.

## Steps
1. Open [handbook/seats/senior-print-designer.md](../../handbook/seats/senior-print-designer.md) before answering anything.
2. Asked who the senior print designer is? The seat sits in Craft cluster. **No owner recorded.** Do not invent a design executive.
3. Asked to set the print spec, the house standard, or "the template we'll reuse"? **No.** Name the decisions that are missing and say they belong to Michael.
4. Asked for a press, stock, trim, colour profile, bleed, imposition, binding, or finish? **The production stack is named missing.** Every one of those stays unanswered.
5. Asked for our address? **Named missing.** It does not go on a printed piece.
6. Asked who prints for us, or asked to get a quote? **No print vendor is recorded.** David McInnis is a vendor **for Cranberry Press**. Dave / Lehi Drew is a **tech** vendor. Name neither as a printer, and request nothing from anyone — that would be a send. Client websites are not a product.
7. Asked for a style guide? **`styleguide-os` is locked.** There is no house style guide in this repo either.
8. Asked to preflight, approve, or set standards for the junior seat? **Both seats are unassigned.** No files and no relationship. See [run-junior-print-designer](../run-junior-print-designer/SKILL.md).
9. Asked who should fill the seat? Not recorded — see [handbook/people.md](../../handbook/people.md). Jhana and Bob have no recorded Role.
10. No KPI is named for this seat. Do not invent a reprint rate or a cost per unit. Point at [handbook/leftovers/senior-print-designer.md](../../handbook/leftovers/senior-print-designer.md).
11. If anything about this seat does go out, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first.

## Never
- Never name a Senior Print Designer. The seat is unassigned.
- Never write a print specification, house standard, master template, colour profile, imposition plan, or preflight checklist.
- Never invent a press, printer, stock, trim size, bleed, binding, or finish.
- Never name Cranberry Press — or anyone else — as our printer, and never request a quote.
- Never invent or fill in the studio address.
- Never invent the junior / senior split, and never preflight, approve, or set standards for the other seat.
- Never touch, clone, or read `styleguide-os` or any other program repo.
- Never invent an accountability or KPI for this seat.
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
