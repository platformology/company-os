## The gate
The seat page is [handbook/seats/pr-media.md](../../handbook/seats/pr-media.md), and this skill does not restate it.

**This seat is unassigned.** There is no holder, no outlet, media contact, news, boilerplate, or spokesperson, and no live job for it to run today. That is the whole honest state of the seat. It reports to [CMO](../../handbook/seats/cmo.md) on paper. No PR programme exists.

## If you were sent here for work
There is none assigned. Say that plainly.

That is not a lookup failure or a page that hasn't been written yet — the seat has no accountabilities recorded because no source records any, and this repo does not write them in ahead of a source. Nothing here needs to be filled in, and no release needs to be produced to make the answer look complete.

## Steps
1. Open [handbook/seats/pr-media.md](../../handbook/seats/pr-media.md) before answering anything.
2. Asked who owns press? The seat reports into [CMO](../../handbook/seats/cmo.md) and is unassigned — see [run-cmo](../run-cmo/SKILL.md). Don't hand the work to the CMO.
3. Asked for a press release, pitch, or media list? There is no news and no contact recorded. Do not draft a release "for when we have news."
4. Asked for a quote? Nobody's words get written for them. Jhana and Bob have no Role to be quoted in.
5. Asked for the track record? Quote a number with its date — 124 (Dec 2022), 128 (Book Retreat era), later 130–131. Never one number alone. See [quote-track-record](../quote-track-record/SKILL.md).
6. Asked for a KPI or Bestseller hit rate? No KPI is named for this seat. Bestseller hit rate is [CCO](../../handbook/seats/cco.md)'s. Point at [handbook/leftovers/pr-media.md](../../handbook/leftovers/pr-media.md).
7. Asked who should fill the seat? Not recorded, and not this skill's guess — see [handbook/people.md](../../handbook/people.md). Jhana and Bob have no recorded Role and don't get assigned one here.
8. If anything about this seat does go out, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first.

## Never
- Never name a PR / Media holder. The seat is unassigned.
- Never contact an outlet, and never write a release, pitch, boilerplate, or quote.
- Never collapse the track record, and never imply a list placement.
- Never borrow Bestseller hit rate from CCO.
- Never invent a KPI, and never quietly reassign this seat's work to the CMO.
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
