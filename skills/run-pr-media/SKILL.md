# Run the PR and Media seat

Reused from: [JGalego/TeamAPI](https://github.com/JGalego/TeamAPI), `docs/spec/teamapi-extended-v1.md` — a seat exists independently of whoever fills it, and can be vacant. Already credited in [`SOURCES.md`](../../SOURCES.md).

## The gate

[handbook/seats/pr-media.md](../../handbook/seats/pr-media.md) is the seat page. This skill does not restate it — open it before answering anything.

**This seat is unassigned.** Michael named the job on 20 Aug 2026. Nobody is in it and no work is assigned to it.

No outlet, journalist, podcast, press list, or past placement is recorded here.

## Steps

1. Open [handbook/seats/pr-media.md](../../handbook/seats/pr-media.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [CMO](../../handbook/seats/cmo.md), whose holder is not recorded either. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no press list and no recorded placement. Say so, and do not build a list out of outlets that sound plausible.
4. Asked what would have to exist first: say it plainly — who fills this seat; any outlet, contact, or past placement.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.

## Never

- Never invent an outlet, a journalist, a contact, or a past placement.
- Never draft a quote in Michael's name, or a client's, and let it out of the building.
- Never pitch, email, or follow up. No send without Michael — a pitch is a send.
- Never collapse the track record into one number for a bio or a pitch — [quote-track-record](../quote-track-record/SKILL.md) quotes it with its dates.
- Never name a holder for this seat, and never hand its work to a nearby seat.
- Never send. No send without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
