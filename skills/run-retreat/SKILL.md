# Run retreat

Reused from: [narrative-io/narrative-skills-marketplace](https://github.com/narrative-io/narrative-skills-marketplace), `docs/authoring-skills.md` ("never duplicate" the reference in the skill body), and [dzhng/skills](https://github.com/dzhng/skills), `skills/authoring/write-skills/SKILL.md` ("keep a single source of truth").

## The gate
The [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5) (Notion) is the single source of truth for how a Book Retreat actually runs. This repo does not restate it — open it before doing anything.

## Who owns what
**Retreat Producer is not VP Retreats** — see [handbook/seats/retreat-producer.md](../../handbook/seats/retreat-producer.md) and [handbook/seats/vp-retreats.md](../../handbook/seats/vp-retreats.md). Don't collapse them into one seat.

## Steps
1. Open the [Retreat SOP](https://app.notion.com/p/3c025e30d68b8185b9a9f19dd56389e5) in Notion.
2. Quote prices only from [handbook/offers.md](../../handbook/offers.md).
3. **Do not invent a retreat date, guest list, or venue** — none of those is sourced in this repo.
4. Dietary, rooming, arrival, AV, and incident fields stay named missing — see the [blank-guest-intake](../blank-guest-intake/SKILL.md) skill.
5. Before anything drawn from a live retreat goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never restate the Retreat SOP in this repo — link it, don't copy it.
- Never invent a retreat date, guest list, or venue.
- Never fill a dietary, rooming, arrival, AV, or incident field from a guess.
- Never treat Retreat Producer and VP Retreats as the same seat.
- Never quote a price not on [handbook/offers.md](../../handbook/offers.md).
- Never send anything from a retreat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
