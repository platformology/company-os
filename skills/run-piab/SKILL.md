## Steps

2. Quote the price only from [handbook/offers.md](../../handbook/offers.md): Platform in a Box — Consult, or Drive $40,000.
3. **Current PIAB cycle time is named missing** — not written down in this repo. If asked how long a PIAB engagement currently takes, say so; don't estimate one.
4. Before anything drawn from a PIAB engagement goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).
