## The gate
The seat page is [handbook/seats/seo-expert.md](../../handbook/seats/seo-expert.md), and this skill does not restate it.

**This seat is unassigned.** There is no holder, no web property, no analytics, no keyword, and no live job for it to run today. That is the whole honest state of the seat. It reports to [CMO](../../handbook/seats/cmo.md) on paper. Client websites are not a product.

## If you were sent here for work
There is none assigned. Say that plainly.

That is not a lookup failure or a page that hasn't been written yet — the seat has no accountabilities recorded because no source records any, and this repo does not write them in ahead of a source. Nothing here needs to be filled in, and no keyword needs to be produced to make the answer look complete.

## Steps
1. Open [handbook/seats/seo-expert.md](../../handbook/seats/seo-expert.md) before answering anything.
2. Asked who owns SEO? The seat reports into [CMO](../../handbook/seats/cmo.md) and is unassigned — see [run-cmo](../run-cmo/SKILL.md). Don't hand the work to the CMO, to Head of Demand, or to Head of Content.
3. Asked for keywords, a query set, or search volume? None is recorded. A keyword invented is an audience invented. Do not write a starter list.
4. Asked to audit a site? No web property is recorded. Do not go find one, and do not open a locked program repo.
5. Asked for traffic, rankings, or a KPI? None is recorded. No KPI is named for this seat. Do not borrow Inbound leads. Point at [handbook/leftovers/seo-expert.md](../../handbook/leftovers/seo-expert.md).
6. Asked to optimise the lead magnet? It has **no Offers row** — see [handbook/offers.md](../../handbook/offers.md) — and does not get a price from here.
7. Asked who should fill the seat? Not recorded, and not this skill's guess — see [handbook/people.md](../../handbook/people.md). Jhana and Bob have no recorded Role and don't get assigned one here.
8. If anything about this seat does go out, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first.

## Never
- Never name an SEO Expert. The seat is unassigned.
- Never invent a keyword, query, search term, or search volume.
- Never write a site audit, title, meta description, or traffic figure.
- Never touch, clone, crawl, or cite a locked program repo.
- Never treat a client website as a product.
- Never invent a KPI, and never quietly reassign this seat's work to the CMO or Head of Demand.
- Never send anything from this seat without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
