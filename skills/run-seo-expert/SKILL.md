## Steps

1. Open [handbook/seats/seo-expert.md](../../handbook/seats/seo-expert.md).
2. Asked who does this work: nobody. This seat is unassigned, and above it is [CMO](../../handbook/seats/cmo.md), whose holder is not recorded either. Route the ask to Michael rather than to a name — see [handbook/people.md](../../handbook/people.md).
3. Asked for the work itself: there is no site, no analytics, and no keyword list. Say so, and do not run the numbers from a public tool and present them as ours.
4. Asked what would have to exist first: say it plainly — who fills this seat; the site, analytics, and keyword list this seat would work from — none is recorded, and the production stack is already a named gap.
5. If anything about this seat goes out, run [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md) first, then stop.
