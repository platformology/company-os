## The gate
The [PA handoff](https://app.notion.com/p/3c125e30d68b8138a686fd8a52313333) (Notion) page is the single source of truth for how a handoff actually runs. This repo does not restate it — open it before doing anything.

## Steps
1. Open the [PA handoff](https://app.notion.com/p/3c125e30d68b8138a686fd8a52313333) page in Notion.
2. **Do not invent who the next PA is, or a tenure end date** — neither is sourced in this repo. If asked, say so.
3. Before anything drawn from a handoff goes anywhere external, run it through [reviews/last-gate-checklist.md](../../reviews/last-gate-checklist.md).

## Never
- Never restate the PA handoff page in this repo — link it, don't copy it.
- Never invent a next PA or a tenure end date.
- Never send anything from a handoff without Michael. No program GitHub. See [handbook/locks.md](../../handbook/locks.md).
